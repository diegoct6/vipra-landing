Qué detecta Vipra

Solo los tipos que de verdad busca.

  • Nombre[PERSON_1] El nombre de una persona.
  • Correo[EMAIL_1] Una dirección de email.
  • Teléfono[PHONE_1] Un número de teléfono.
  • IBAN[IBAN_1] Un número de cuenta internacional.
  • Tarjeta[CREDIT_CARD_1] Un número de tarjeta.
  • Documento[NATIONAL_ID_1] Forma de número de la Seguridad Social de EE. UU. Otros documentos, como el DNI, no entran.
  • Dirección IP[IP_ADDRESS_1] Una dirección IPv4.
  • Clave de API[API_KEY_1] Formas habituales de claves de API.
  • Token[JWT_1] Un JSON Web Token.
  • Enlace secreto[URL_SECRET_1] Un enlace que lleva una contraseña o un token.

Preguntas

Respuestas cortas.

¿Lo que escribo sale de mi dispositivo?

No. La revisión ocurre en Chrome. Lo que escribes no se sube. La clave de licencia solo se comprueba al activar De por vida, a través de Lemon Squeezy.

¿Dónde funciona?

En cualquier campo de texto. Los chats de IA, como ChatGPT, son el caso principal. También vale para el correo, los formularios y los documentos. Si una web pinta el texto de una forma rara, fíate de la lista de revisión.

¿Qué sustituye?

Nombres, correos, teléfonos, tarjetas, IBAN y documentos, además de algunas formas de secretos (IPs, claves de API, tokens, enlaces con contraseña). Cada uno pasa a un token como [EMAIL_1].

¿Qué incluye el plan gratis?

Cinco protecciones al día. De por vida son €4,99, una sola vez, con protecciones ilimitadas. Sin suscripción.
