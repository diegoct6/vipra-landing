What Vipra detects

Only the types it actually looks for.

  • Name[PERSON_1] A person’s name.
  • Email[EMAIL_1] An email address.
  • Phone[PHONE_1] A phone number.
  • IBAN[IBAN_1] An international bank account number.
  • Card[CREDIT_CARD_1] A payment card number.
  • National ID[NATIONAL_ID_1] A US Social Security number shape. Other national IDs are not claimed.
  • IP address[IP_ADDRESS_1] An IPv4 address.
  • API key[API_KEY_1] Common API key shapes.
  • Token[JWT_1] A JSON Web Token.
  • Secret link[URL_SECRET_1] A link carrying a password or token.

Nicknames and vague hints can slip through. If you are unsure, take them out yourself.

FAQ

Short answers.

Does what I type leave my device?

No. The check runs in Chrome. Nothing you type is uploaded. The license key is checked only when you activate Lifetime, through Lemon Squeezy.

Where does it work?

Any text field. AI chats such as ChatGPT are the main case. Email, forms, and docs work too. If a site draws text in an unusual way, trust the review list.

What does it replace?

Names, emails, phones, cards, IBANs, and ID numbers, plus a few secret shapes (IPs, API keys, tokens, secret links). Each becomes a token like [EMAIL_1].

What does free include?

Five protections a day. Lifetime is €4.99 once for unlimited protections. No subscription.

Do I need an account?

No.
