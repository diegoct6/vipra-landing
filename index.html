What Vipra detects

Only the types it actually looks for.

Labels match the review panel. Protect turns each one into a numbered token.

  • Name[PERSON_1] A person’s name.
  • Email[EMAIL_1] An email address.
  • Phone[PHONE_1] A phone number.
  • IBAN[IBAN_1] An international bank account number.
  • Card[CREDIT_CARD_1] A payment card number.
  • National ID[NATIONAL_ID_1] A US Social Security number shape. Other national IDs are not claimed.
  • IP address[IP_ADDRESS_1] An IPv4 address.
  • API key[API_KEY_1] Common API key shapes.
  • Token[JWT_1] A JSON Web Token.
  • Secret link[URL_SECRET_1] A link carrying a password or token.

A private story with none of these can still be something you would not send. Vipra will not catch every nickname, paraphrase, or creative disguise. If you are unsure, take it out yourself.

FAQ

Short answers.

Does my prompt go to your servers?

No. Vipra reads the field you are editing so it can show what it found and protect it. That stays in your browser. Your prompt is not uploaded to Vipra. Lifetime checkout talks only to the payment provider, separate from what you typed.

Does it work on ChatGPT?

Yes. The ChatGPT message field is the one we design around. Vipra sits beside that field: a count, a review, and Protect.

Does it work in Gmail?

Gmail’s compose box is an editable field, so Vipra can review it too. Some sites draw text in an unusual way. When a highlight cannot line up, the review list is the reliable view.

What happens after 5 protections?

Free includes five protections each day. When those are used, wait until the next day or unlock Lifetime for unlimited protections. Lifetime is €4.99, paid once.

Is Lifetime one payment?

Yes. €4.99 once, for unlimited protections. It is not a subscription, and there is no renewal charge.

What about updates?

Vipra updates through Chrome, like other extensions. Updates are not a second subscription. Lifetime stays one payment for unlimited protections.

Do I need an account?

No. You can install and use Vipra without an account.

What does it detect?

Name, email, phone, IBAN, card, national ID (US Social Security number shape), IPv4 address, common API key shapes, JSON Web Tokens (shown as Token), and secret links. It will not catch every sensitive sentence. Coverage is that list, on your device.
