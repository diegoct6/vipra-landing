# Vipra

Static marketing site for [Vipra](https://vipra.app), a privacy Chrome extension. Plain HTML, CSS, and JavaScript. There is no build step.

Preview locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

GitHub Pages publishes this repository on every push to `main`. The public site is [https://vipra.app](https://vipra.app).
